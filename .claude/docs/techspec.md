# Tech spec: portfolio chat API

Hexagonal, kept small: routes call use cases, use cases talk to ports, adapters implement ports. Decisions behind it
live in the author's project notes (2026-11-06).

## Mapa de Módulos

| `api/app/adapters/worker_queue.py` | adapters | `ChatModel` on Anthony's PC through Redis: pushes the job (system, transcript, deadline) to `chat:jobs` and streams `chat:res:{id}` back (`{d: piece}` messages, then `{end: answer}`); offline at once when no worker polled in 60 s (`chat:worker:seen`) or 10 jobs are waiting, on timeout (even mid-stream) or an empty answer; the contact line never leaves the adapter (`without_contact`). | `api/worker/pc_worker.py` | separate program for the isolated chat worker (WSL distro or VM; outside `app/`, not in the API image) | Long-polls `/api/worker/next` over one kept-alive HTTPS connection, runs `claude -p` hardened (no tools at all: `--tools ""` plus `--disallowedTools "*"`, one turn, `--safe-mode`, `--restricted`, dontAsk, no MCP, hooks, commands or session, empty folder, minimal environment, `--include-partial-messages`), refuses the run before any text unless the first event is a clean init, streams text deltas to `/chunks` in ~0.2 s batches, stops on any `*tool_use` block (tool_use, server_tool_use, mcp_tool_use) or denial (`Unsafe`: empty answer plus the alert label), hands the final text back; images go in the stdin message as PNG blocks. ## Site (`site/src`)

React Router v7 in framework mode, prerendered to static HTML (`ssr: false`, `prerender: true`) and served by nginx.
Folders follow bulletproof-react: `app` (routes), `features`, `components`, `content`, `hooks`, `lib`, `styles`.
Identity: direction C (Archivo, big numbers, #fafaf7 / #0b0b0b) with a light "Matrix" touch chosen by the author on 08/11: green
accent (#047a46 on light, #3dfc8a on dark, neon #3dfc8a for filled shapes), labels as a terminal prompt in IBM Plex Mono,
and a character rain behind the top. Red (#d12d25 / #ff4d43) is kept only for errors.
